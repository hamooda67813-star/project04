# Personal Portfolio

## About the Project

This project is a personal portfolio website created from scratch
using HTML5, CSS3, and JavaScript.

The goal of the project is to present my background, skills,
projects, hobbies, and contact information in a responsive
and modern web page.

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Git

## Website Sections

The portfolio contains the following sections:

- About Me
- Skills
- Projects
- Hobbies
- Contact
- Footer

## Projects

The portfolio presents four projects:

- Project 00 - Personal Portfolio
- Project 01 - Python Project
- Project 02 - Networking Project
- Project 03 - AI Project

## Interactive Feature

The website includes a theme switcher button.

When the user clicks the "Change Theme" button:

1. A click event is triggered.
2. JavaScript executes the event callback.
3. The `light-theme` class is added or removed.
4. CSS changes the appearance of the page.

This allows the user to switch between the dark theme
and the light theme.

## Responsive Design

The website is responsive and adapts to different screen sizes.

CSS media queries are used to improve the layout on tablets
and mobile devices.

Flexbox and CSS Grid are used to organize the content.
